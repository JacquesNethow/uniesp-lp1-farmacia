# Sistema de Farmácia

Um sistema de gerenciamento de farmácia desenvolvido em Java para praticar Programação Orientada a Objetos (POO) e arquitetura em camadas.

O projeto realiza o controle de medicamentos, clientes, fornecedores, funcionários e vendas, simulando a estrutura de uma aplicação Spring Boot, porém utilizando Java puro e armazenamento em memória.

## Objetivo

O sistema foi organizado seguindo padrões utilizados em aplicações Spring Boot para facilitar futuras implementações, atualmente o projeto roda localmente e utiliza `ArrayList` para persistência dos dados.
